# Samrat Drug Agency — Website

A responsive HTML/CSS/JavaScript-only frontend for Samrat Drug Agency.

## Included
- Responsive landing page
- Dynamic SVG/CSS medical logo
- Medicine portfolio with search
- India + international reference medicine list
- Research desk
- Compliance/certification document placeholders
- Order / rate / availability enquiry form
- Quick enquiry popup
- WhatsApp enquiry integration
- CDSCO official drug-search reference
- Mobile navigation

## Important before publishing
1. Replace the demo medicine catalogue with the products you actually distribute.
2. Verify every manufacturer/brand, product status, licence, certificate and market authorization.
3. Add genuine Drug Distribution Licence, GST and manufacturer quality documents only.
4. Do not claim a medicine or certificate is “CDSCO approved”, “WHO certified”, “GMP certified”, etc. unless the exact status/document is verified.
5. For Schedule H/H1/X or other controlled/prescription products, implement the legally required prescription/licence workflow and do not treat the public website as an unrestricted retail pharmacy.
6. The current order/enquiry forms open WhatsApp and do not store orders. A production order system needs a secure backend/database, authentication, document storage and audit logging.
